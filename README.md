Entry for **One Line, One Laugh: Roast Your Fridge**
([make.fun](https://make.fun/competitions/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521)):
one line roasting my fridge, written by `main.py` to `/output/entry.txt`.

## The line

> My fridge's ice maker sounds like a dying robot clearing its throat at 3 a.m., then drops exactly one cube, like it's doing me a favour.

136 characters, one line, no setup sentence — a specific, recognisable detail
(the ice maker's 3 a.m. groan and its single-cube output) with the twist paying
off in the last words.

## How it was chosen

10 candidates were written and ranked by hand against the judge brief in the
kit (specific detail first, twist in the last words, fresh rather than a
worn-out fridge joke), with pairwise checks against the strongest rivals.
The full candidate list and reasoning are in `candidates.md` in the build
workspace. No judge API or proxy tournament was used to pick the line.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

Deterministic: same bytes on every run, no network, no randomness, no secrets.
